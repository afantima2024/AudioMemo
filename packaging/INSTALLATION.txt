INSTALL
Close AudioMemo normally, then run AudioMemo-<version>-Setup-x64.exe.
The installer supports English and Simplified Chinese.
It installs for the current Windows user in:
  %LOCALAPPDATA%\Programs\AudioMemo
No administrator permission or certificate installation is required.
A Start menu shortcut is created. A desktop shortcut is optional.
The installer does not start AudioMemo or begin recording automatically.

This package is unsigned. Windows SmartScreen or your organization's policies
may warn about or block it. A trusted code-signing certificate is needed for a
signed distribution; this installer does not change or bypass those protections.
The SHA-256 file identifies this exact download but is not a publisher signature.

FIRST USE
Open AudioMemo from the Start menu. On a new PC, finish the setup wizard:
choose at least one working microphone/playback device and a writable recording
folder. Speech and LLM setup may be skipped and completed later in Settings.
Recording itself does not require a model or online account.

The .NET desktop runtime, FFmpeg, and speech engine libraries are included.
For local speech, install Microsoft's Visual C++ 2022 x64 Redistributable if
it is missing, and download a speech model in AudioMemo's Settings:
  https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist
Ollama, Copilot CLI, AI accounts, and model weights are optional and are not
bundled. The installer does not download or silently install these components.
Open AudioMemo logo > Help & About for the offline user guide and shortcuts.

EXISTING PORTABLE USERS / UPDATES
Settings and models in %LOCALAPPDATA%\AudioMemo and your selected recording
folder are reused. Existing portable program folders are not moved or deleted.
Keep only one copy of AudioMemo running. Close it normally before installing
an update; setup does not force-close the application.
Run a later Setup.exe to update the same per-user program location.
Do not use the program installation folder as your recording or backup folder.

UNINSTALL
Use Windows Settings > Apps > Installed apps > AudioMemo > Uninstall.
Only installer-owned program files and its shortcuts are removed.
Your recordings, settings, downloaded models, and message history are retained.
Added files and nonempty folders are not recursively deleted.

Third-party copyrights and licenses are separate from AudioMemo's credits.
Retain support\Licenses and support\Docs\THIRD-PARTY-NOTICES.txt.
