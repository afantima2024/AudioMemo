AudioMemo's Windows x64 speaker runtime

The shipped sherpa-onnx-c-api.dll is built from the unmodified sherpa-onnx
v1.13.8 source with SHERPA_ONNX_ENABLE_TTS=OFF. The stock NuGet native
binary is explicitly excluded. Disabling TTS excludes Piper/eSpeak-ng;
these unused text-to-speech implementations are not linked into this build.
Python, binaries/examples, WebSocket support, and PortAudio are also disabled.
Speaker diarization and the C API remain enabled.
